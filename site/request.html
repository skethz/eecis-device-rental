⚠ Rental rules — please read before you request

  • Initial request: To rent a device from H66, a user must submit a request to the lab manager (Seungki Hong, hongse@ethz.ch) via the device list. The request specifies the rental period, your name and group.
  • Extensions: If you wish to extend the rental period, you must submit another request via My rentals.
  • Returns: When returning the device, you must submit the return record via My rentals.
  • Overdue warnings: If the rental period expires and no return is recorded in the system, a warning email is sent automatically to you, your lab manager and professor, and our lab manager — every day until the return or extension request is recorded.
  • New devices: Group members who purchase a device must request to add it on the Devices page; it appears in the list once the lab manager approves it.
